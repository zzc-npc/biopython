# 大功能：从数组里精确取出你要的部分。
你以后处理 RNA 数据会遇到：
取第 5 条序列的长度 → 单个索引
取前 10 条序列 → 切片
取出所有长度大于 100 的序列 → 布尔筛选
取出所有序列的前 4 列碱基计数 → 二维切片
把长度小于 50 的序列去掉 → 布尔筛选 + 赋值
这一课的核心就一句话：先定位，再取值。

# random 的使用
## 1. 正态分布（Normal）
生成一个 2x4 的矩阵，每个元素均来自该分布
R = random('Normal', 1, 5, [2, 4]);
## 2. 均匀分布（Uniform）
% 生成一个 3x4 的均匀分布随机数矩阵
R = random('Uniform', 0, 1, [3, 4]);
## 3. 泊松分布（Poisson）
生成一个 1x100 的向量
R = random('Poisson', 5, [1, 100]);
## 4. 离散均匀分布（unid）
% 生成 1 或 2，模拟抛硬币（1 代表正面，2 代表反面）
x = random('unid', 2, [1, 1e5]); 

% 如果要生成 0 或 1，可以再减去 1
x0 = x - 1;
## 5. 生成与现有数组同大小的随机数矩阵
A = [3 2; -2 1];
% 生成一个与 A 同大小的矩阵，元素来自稳定分布
R = random('Stable', 2, 0, 1, 0, size(A));
